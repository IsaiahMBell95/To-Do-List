# To-Do-List

### Purpose

The purpose of this application is to build a To-Do list using Python.  It gives the ability for you to add tasks, view tasks, mark tasks as completed and delete tasks. 

### How It Functions

<img width="116" height="61" alt="image" src="https://github.com/user-attachments/assets/e8b612f3-087f-4ce4-af32-f6e34f6f6d30" />

The application allows you to choose an option 1-5.

1) Add Task - This option allows you to add a task (ex. Grocery Shopping) to the to-do list.

2) View Tasks - Once a task is added, you can view that task. The task will have an "X" beside it meaning it is a task that has not been completed.

3) Mark Task as Completed - This allows you to mark the task complete. Once complete the task will show a "✓" next to it showing it's been done. If you enter an invalid number, or letter the function will return to the main screen and you'll receive a note saying to enter a valid number. 

4) Remove Task - This allows you to remove the task. If you enter an invalid number, or letter the function will return to the main screen and you'll receive a note saying to enter a valid number.

5) Exit - You can exit the application.
